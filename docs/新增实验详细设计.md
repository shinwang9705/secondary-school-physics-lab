# 新增 28 项实验详细设计 · v1.0

新增规格与解析模型共用 public/physics/laboratory.js，浏览器采用 SVG 实验器材图、滑块/数值/选择框、手动测量、记录和数据图表。服务端验证每一行参数、步数、分度和读数后重新计算。目录内其余 14 项保留此前电路、几何光学、力学模型。

固定步长使用整数 ticks，恢复/改参数后暂停；定位时间是教学观察功能，并不证明真实计时操作。运动触及终点停止；动态实验参数变化开始新一轮。RC 切换充放电保留上一阶段电压（按 0.01 V 网格舍入），可设置独立初始电压作对照。图表可以逐行选择纳入数据，拟合用于分析，同一轮条件由实验者选择。

## j01 用托盘天平测量物体的质量

- 目标：空载调平；选择砝码并移动游码，测量三个物体。
- 参数：待测物体（0=物体 A，1=物体 B，2=物体 C）；右盘砝码总质量 / g（0 至 300，步距 5）；游码 / g（0 至 5，步距 0.1）；空载零点偏差 / g（-1 至 1，步距 0.1）。
- 记录：测得质量 / g。
- 模型：理想托盘天平，游码分度 0.1 g；砝码组合以总质量设置，空载偏差必须调零。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## j02 测量固体和液体的密度

- 目标：用质量与体积测密度；分别记录三种体积的固体和液体测量。
- 参数：测量类型（0=固体排水法，1=液体差量法）；物体/液体体积 / cm³（20 至 80，步距 5）；量筒初始液面 / mL（20 至 80，步距 5）；固体状态（0=未浸入，1=全部浸入）。
- 记录：计算密度 / g·cm⁻³。
- 模型：理想铝块 2.7 g/cm³、液体 0.8 g/cm³；液体采用空杯与满杯差量，固体需完全浸入且不溶于液体。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## j03 用常见温度计测量温度

- 目标：正确浸入温度计，等待稳定，测量至少三种温度。
- 参数：液体温度 / °C（-10 至 100，步距 5）；温度计浸入深度 / cm（0 至 12，步距 0.5）；接触状态（0=悬置不接触杯壁，1=接触杯壁/底部）。
- 记录：温度计读数 / °C。
- 模型：教学温度计范围 −20—110 °C、分度 1 °C；一阶响应时间常数 2 s，不模拟热损失。
- 仿真步长 0.02 s；最多 1000 步；运行显示倍率 2。

## j04 用刻度尺测量长度、用表测量时间

- 目标：读取两端刻度之差；测三个物体并完成至少一次起止计时。
- 参数：器材（0=刻度尺，1=秒表）；待测物体（0=物体 A，1=物体 B，2=物体 C）；物体左端刻度 / cm（0 至 5，步距 0.1）。
- 记录：长度 / cm，或计时 / s。
- 模型：刻度尺分度 1 mm，可估读；计时 dt=0.02 s。移动物体改变起点，长度不能直接使用右端刻度。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## j10 探究水在沸腾前后温度变化的特点

- 目标：加热并记录升温段、沸腾段各至少两组，比较温度随时间的变化。
- 参数：水的质量 / kg（0.1 至 0.5，步距 0.1）；加热功率 / W（100 至 600，步距 100）；初始温度 / °C（20 至 80，步距 10）。
- 记录：测量温度 / °C。
- 模型：标准大气压下水沸点 100 °C，c=4200 J/(kg·K)，汽化潜热 2.26 MJ/kg；无散热，蒸干后停止。
- 仿真步长 0.5 s；最多 3600 步；运行显示倍率 30。

## j11 探究滑动摩擦力大小与哪些因素有关

- 目标：匀速拉动时读取测力；分别改变压力和表面，每轮三种条件。
- 参数：物体质量 / kg（0.2 至 2，步距 0.2）；接触表面（0=光滑木板 μ=0.2，1=粗糙木板 μ=0.4，2=砂纸 μ=0.6）；拉动方式（1=电机匀速拉动，0=静止增加拉力）；静止时施加拉力 / N（0 至 15，步距 0.1）；匀速速度 / m·s⁻¹（0.1 至 1，步距 0.1）。
- 记录：摩擦力 / N。
- 模型：g=10 m/s²，滑动摩擦 μN；静摩擦上限约定为 1.2μN。匀速由外部电机维持；不模拟粘滑与表面磨损。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## j12 探究液体压强与哪些因素有关

- 目标：分别改变深度、密度和探头方向，各记录三种条件。
- 参数：液体密度 / kg·m⁻³（800 至 1200，步距 100）；探头深度 / m（0.02 至 0.4，步距 0.02）；探头朝向（0=向上，90=水平，180=向下）。
- 记录：测量压强 / Pa。
- 模型：静止液体表压 p=ρgh，g=10；U 形管液体密度 1000 kg/m³，液柱差 Δh=p/(ρg)。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## j18 探究通电螺线管外部磁场的方向

- 目标：观察磁针，分别反转电流、绕线方向，记录两种磁极响应。
- 参数：电流 / A（-1 至 1，步距 0.2）；绕线方向（1=正向绕线，-1=反向绕线）；磁针位置（0=螺线管内，1=右侧轴线上，2=左侧轴线上）。
- 记录：磁针 N 极方向：右 +1，左 −1。
- 模型：长螺线管轴向理想场，B≈μ₀nI，n=400 m⁻¹；左右外轴线上方向相同，不模拟边缘三维场。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## j19 探究导体在磁场中运动时产生感应电流的条件

- 目标：比较静止/运动、闭合/断开条件，并反转运动方向。
- 参数：磁场方向（1=正向，-1=反向）；导体速度 / m·s⁻¹（-2 至 2，步距 0.1）；有效导体长度 / m（0.2 至 1，步距 0.1）；导线方向（1=正向，-1=反向）；回路电阻 / Ω（10 至 100，步距 10）；回路开关（1=闭合，0=断开）。
- 记录：感应电流 / mA。
- 模型：匀强磁场 0.2 T、直导体切割磁感线，ε=BLv；回路闭合时 I=ε/R，无电感瞬态。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h01 测量做直线运动物体的瞬时速度

- 目标：运行小车穿过光电门，以遮光片宽度/遮光时间估计速度，比较三种条件。
- 参数：初速度 / m·s⁻¹（0.5 至 2，步距 0.1）；加速度 / m·s⁻²（0 至 2，步距 0.1）；光电门位置 / m（1 至 5，步距 0.5）；遮光片宽度 / m（0.005 至 0.1，步距 0.005）。
- 记录：瞬时速度估计 / m·s⁻¹。
- 模型：恒加速度模型；光电门时间解析计算。遮光片 ≤2 cm 时作为短区间瞬时速度估计，不把平均速度无条件当作瞬时速度。
- 仿真步长 0.005 s；最多 2400 步；运行显示倍率 2。

## h03 探究两个互成角度的力的合成规律

- 目标：调整替代单力，使作用效果与两个力相同；记录三种夹角条件。
- 参数：力 F₁ / N（0.5 至 5，步距 0.1）；F₁ 方向 / °（0 至 180，步距 1）；力 F₂ / N（0.5 至 5，步距 0.1）；F₂ 方向 / °（0 至 180，步距 1）；替代单力 / N（0 至 10，步距 0.01）；替代单力方向 / °（0 至 180，步距 1）。
- 记录：测得合力 / N。
- 模型：共点力矢量合成；弹性标记点位移与力成正比，替代效果差 ≤0.06 N。不模拟橡皮条非线性。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h05 验证机械能守恒定律

- 目标：释放物体，在三个不同高度记录速度和机械能；比较无阻力与有阻力。
- 参数：释放高度 / m（0.5 至 3，步距 0.5）；物体质量 / kg（0.1 至 2，步距 0.1）；阻力系数 / kg·s⁻¹（0 至 1，步距 0.1）。
- 记录：机械能 Ep+Ek / J。
- 模型：g=9.8；线性空气阻力 bv。接地显示触地前瞬间速度，不模拟碰撞；守恒验证需阻力为零。
- 仿真步长 0.005 s；最多 1000 步；运行显示倍率 0.5。

## h06 探究平抛运动的特点

- 目标：同一次平抛在三个时刻测量水平位移和竖直下降量。
- 参数：水平初速度 / m·s⁻¹（2 至 10，步距 1）；释放高度 / m（0.5 至 3，步距 0.5）。
- 记录：水平位移 / m；竖直下降量 / m。
- 模型：理想平抛，无空气阻力，g=9.8；落地停止。水平匀速、竖直自由落体。
- 仿真步长 0.005 s；最多 300 步；运行显示倍率 0.5。

## h07 探究向心力大小与半径、角速度、质量的关系

- 目标：分别只改变质量、半径、角速度，每轮至少三种条件。
- 参数：质量 / kg（0.02 至 0.2，步距 0.01）；半径 / m（0.05 至 0.3，步距 0.01）；角速度 / rad·s⁻¹（2 至 12，步距 1）。
- 记录：向心力 / N。
- 模型：理想匀速圆周运动，F=mω²r；外部装置保持角速度，不模拟绳伸长和转轴摩擦。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h08 观察电容器的充、放电现象

- 目标：分别在充电和放电阶段记录三个时刻的 Uc、I，观察指数变化。
- 参数：电源电压 / V（3 至 6，步距 0.5）；电阻 / Ω（100 至 1000，步距 100）；电容 / μF（1000 至 10000，步距 1000）；开关位置（0=充电，1=放电）；回路开关（1=闭合，0=断开）；阶段初始电容电压 / V（0 至 6，步距 0.01）。
- 记录：电容电压 / V；电流 / mA。
- 模型：理想 RC，时间常数 τ=RC；切换开关保留电容电压，电源/器材参数变更开启新一轮。无漏电和击穿。
- 仿真步长 0.02 s；最多 3000 步；运行显示倍率 2。

## h09 长度的测量及其测量工具的选用

- 目标：调零后移动测量开口到接触物体，选用三种工具并记录分度差异。
- 参数：测量工具（0=毫米刻度尺，1=0.1 mm 游标卡尺，2=0.01 mm 螺旋测微器）；待测物体（0=物体 A，1=物体 B，2=物体 C）；测量开口 / mm（0 至 20，步距 0.01）；零点误差 / mm（-0.1 至 0.1，步距 0.01）。
- 记录：测得长度 / mm。
- 模型：卡尺/测微器按理想刻度读数，需接触且不得夹入物体；不模拟测力棘轮与弹性压缩。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h10 测量金属丝的电阻率

- 目标：测长度、直径和 U/I，计算 ρ=Rπd²/(4L)；同一材料三组条件。
- 参数：金属丝（0=铜，1=镍铬合金）；金属丝长度 / m（0.5 至 2，步距 0.1）；直径 / mm（0.1 至 0.6，步距 0.01）；测量电压 / V（0.001 至 1，步距 0.001）。
- 记录：电阻率 / (10⁻⁸ Ω·m)。
- 模型：恒温理想金属丝，无接触电阻；0.6 A 电流量程，过流需降压。铜电阻率取 1.68×10⁻⁸、镍铬取 1.1×10⁻⁶ Ω·m。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h11 用多用电表测量电学中的物理量

- 目标：分别选择电压、电流、电阻档，设置接法、极性、量程；电阻档必须断电并调零。
- 参数：表档位（0=直流电压，1=直流电流，2=电阻）；表笔接法（0=并联，1=串联，2=隔离待测电阻）；电源电压 / V（1 至 6，步距 0.5）；待测电阻 / Ω（10 至 1000，步距 10）；待测电路（1=通电，0=断电）；表笔极性（1=正确，-1=接反）；电压量程 / V（6=6 V，30=30 V）；电流量程 / A（0.6=0.6 A，3=3 A）；电阻量程 / Ω（100=100 Ω，1000=1 kΩ，10000=10 kΩ）；欧姆档调零偏差 / Ω（-5 至 5，步距 1）。
- 记录：读数：V、A 或 Ω。
- 模型：多用表独立教学器材；电流档内阻 0.1 Ω，电压档理想内阻无穷大；电阻档不测带电电路。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h12 测量电源的电动势和内阻

- 目标：改变负载测三组 U、I，以 U=E−Ir 拟合并填写 E、r。
- 参数：电源电动势 / V（1.5 至 6，步距 0.5）；内阻 / Ω（0.2 至 2，步距 0.1）；负载 / Ω（2 至 100，步距 1）；回路开关（1=闭合，0=断开）。
- 记录：端电压 / V；电流 / A。
- 模型：理想电源串联内阻，U/I 读数采用理想仪表；最大安全测量电流 0.6 A。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h13 验证动量守恒定律

- 目标：运行两小车碰撞，改变质量/初速度完成三次，比较前后总动量。
- 参数：小车 1 质量 / kg（0.1 至 1，步距 0.1）；小车 2 质量 / kg（0.1 至 1，步距 0.1）；小车 1 初速度 / m·s⁻¹（0.5 至 3，步距 0.1）；小车 2 初速度 / m·s⁻¹（-1 至 1，步距 0.1）；恢复系数 e（0 至 1，步距 0.1）。
- 记录：碰撞前总动量 / kg·m·s⁻¹；碰撞后总动量 / kg·m·s⁻¹。
- 模型：理想一维无外力碰撞，e=0—1；动量守恒不等于动能守恒。未模拟形变细节。
- 仿真步长 0.01 s；最多 1000 步；运行显示倍率 1。

## h14 用单摆测量重力加速度的大小

- 目标：小摆角下计时多个完整周期；至少三种摆长，计算重力加速度。
- 参数：摆长 / m（0.3 至 1.5，步距 0.1）；初始摆角 / °（2 至 20，步距 1）；计时周期数（5 至 20，步距 1）。
- 记录：由多周期计时计算 g / m·s⁻²。
- 模型：周期采用小角公式并加入 θ²/16 首阶振幅修正，验证限定 ≤10°；摆线无质量、无阻尼。
- 仿真步长 0.02 s；最多 4000 步；运行显示倍率 4。

## h15 测量玻璃的折射率

- 目标：在同一玻璃块上测三种入射角和折射角，计算 sin i/sin r。
- 参数：玻璃块（0=玻璃 A，1=玻璃 B，2=玻璃 C）；入射角 / °（5 至 80，步距 5）。
- 记录：测量折射角 / °；计算折射率。
- 模型：空气入射平行玻璃块，理想斯涅尔定律；不模拟色散、实际插针和厚度误差。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h16 用双缝干涉实验测量光的波长

- 目标：移动两个游标到亮纹，跨越多个间隔；改变屏距测三组并计算波长。
- 参数：光波长 / nm（400 至 700，步距 50）；缝到屏距离 / m（0.5 至 2，步距 0.1）；双缝间距 / mm（0.2 至 1，步距 0.1）；测量条纹间隔数（1 至 6，步距 1）；起点游标 / mm（-20 至 20，步距 0.01）；终点游标 / mm（-20 至 20，步距 0.01）。
- 记录：计算波长 / nm。
- 模型：理想双缝、单色相干光、小角近似 Δx=λL/d；游标必须对准相应亮纹，不模拟包络衍射。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h17 探究影响感应电流方向的因素

- 目标：固定其他条件，分别反转磁场、运动和导线方向，记录电流符号。
- 参数：磁场方向（1=正向，-1=反向）；导体速度 / m·s⁻¹（-2 至 2，步距 0.1）；有效导体长度 / m（0.2 至 1，步距 0.1）；导线方向（1=正向，-1=反向）；回路电阻 / Ω（10 至 100，步距 10）；回路开关（1=闭合，0=断开）。
- 记录：感应电流 / mA。
- 模型：ε=BLv，符号由磁场、速度和导线方向共同确定；规定正向对应检流计右偏。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h18 探究变压器原、副线圈电压与匝数的关系

- 目标：交流输入下改变匝数比，测三组副线圈有效值；比较稳态直流。
- 参数：原线圈匝数（100 至 1000，步距 50）；副线圈匝数（50 至 1000，步距 50）；输入有效值 / V（6 至 24，步距 2）；交流频率 / Hz（50 至 100，步距 10）；输入类型（0=正弦交流，1=稳态直流）。
- 记录：副线圈有效值 / V。
- 模型：理想空载变压器，U₂/U₁=N₂/N₁；直流稳态无感应电压，不模拟开关瞬态、饱和、损耗和负载。
- 仿真步长 0.002 s；最多 1000 步；运行显示倍率 0.2。

## h19 利用传感器制作简单的自动控制装置

- 目标：选择传感器与阈值，改变输入量，记录至少三种条件且覆盖执行器开/关。
- 参数：传感器（0=光敏电阻，1=NTC 热敏电阻）；照度 / lx（0 至 1000，步距 50）；温度 / °C（0 至 80，步距 5）；比较阈值 / V（0.5 至 4.5，步距 0.1）；执行器触发条件（1=电压高于阈值，0=电压低于阈值）。
- 记录：传感器分压 / V；执行器状态：开 1，关 0。
- 模型：教学光敏响应与 B=3950 K 的 NTC 模型，5 V/10 kΩ 分压；理想比较器，无迟滞、继电器延时和器件噪声。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h20 用油膜法估测油酸分子的大小

- 目标：从方格估计油膜面积，以稀释倍数和滴数算纯油体积；三种条件重复估测。
- 参数：稀释倍数（500 至 2000，步距 100）；1 mL 溶液滴数（20 至 100，步距 5）；油膜样品（0=样品 A，1=样品 B）。
- 记录：估计油膜面积 / cm²；估计分子大小 / nm。
- 模型：理想单分子层，油分子大小样品 A=1 nm、B=1.5 nm；1 mL 定容、等体积液滴，面积估读允许 10%。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## h21 探究等温情况下一定质量气体压强与体积的关系

- 目标：缓慢改变活塞位置，同一温度测三组 p、V 并比较 pV；观察快速压缩偏离。
- 参数：气体体积 / mL（20 至 100，步距 5）；恒温浴温度 / K（273 至 350，步距 1）；压缩方式（0=缓慢等温，1=快速绝热）。
- 记录：测量压强 / kPa；pV / kPa·mL。
- 模型：封闭理想气体；参考态 100 kPa、50 mL、298 K，绝热 γ=1.4；无漏气与活塞摩擦。
- 仿真步长 0.02 s；最多 500 步；运行显示倍率 1。

## 判定与信任边界

至少三组有效原始记录；服务端按记录时条件复算，数值容差 2% 或分度，油膜面积允许 10%。各实验还需完成规定的控制变量、重复测量、档位或运动阶段；规则定义见 laboratoryChecks，正例及错误/重复/越界测试见 tests/laboratory.test.mjs。教师结论与 0—100 分独立保存，可追加改判历史；自动 PASS 只表示基础检查通过。

未模拟真实接触与流体、材料非线性、复杂三维装置或连续可信考试操作。自由电路台仍采用既有模型，不能据此声称具有完整电表调零时序考核。正式教学上线需逐实验教研验收，真实考试还需独立身份与监考策略。
