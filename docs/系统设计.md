# 系统设计（优化版）· v1.0

数据库使用 WAL 和外键。启动执行幂等增量迁移，保留旧用户、原始记录及评分。

| 表 | 作用 |
| --- | --- |
| users/auth | scrypt 密码、启停、角色、班级与随机 token 摘要 |
| classes/class_teachers | 班级、多教师带班，兼容原主带班字段 |
| tasks | 班级、实验、说明、UTC 截止时间 |
| sessions | 所有者、实验、任务、原始状态、修订、状态、版本、提交时间和结果 |
| events | 每次成功保存的完整快照及 STATE/UNDO/REDO/RESET |
| keyframes | 本地 PNG BLOB、实例和保存修订 |
| audit | 登录、授权拒绝、账号维护、任务、提交、评分、备份与外部解释 |

实例模型版本：既有电学/光学 0.1.0；六项力学 0.2.0；新增 28 项 1.0.0。规则与资产使用对应版本，旧实例按原编号补齐。未实现未知模型版本之间的数据转换；使用历史程序备份恢复或导出后新建实例。

PUT sessions 只允许所有者修改草稿，revision 冲突返回 409；状态/修订事件事务保存。提交先复算已保存数据，随后锁定，重复提交返回原结果。教师评分 0—100、COMMENT/APPROVED/REVISE 与 note 追加历史，保留自动结果；latest teacherAssessment 供任务统计显示，其他历史保留。

任务实例必须匹配学生班级与实验编号。逾期仍可提交，由 submitted_at > due_at 标记；同任务允许多个草稿/提交，以便补做。统计列出每位学生与全部实例，不只看列表最近 200 条。

接口：/api/bootstrap、setup、login、me、logout；users（创建/修改/停用/重置密码）、password（本人修改）；classes（创建/改名/多教师）；tasks、tasks/:id/submissions；sessions、events、submit、review；report?format=json/csv/html/pdf；keyframes、explain；config、backups、audit。

浏览器回放只恢复快照供查看，不写回原记录；关闭后重新加载最新保存状态。新实验保存最后一次操作语义及参数/仿真时间，不能还原修订之间所有动作；旧实验保留完整快照但无细粒度动作轨迹。

关键帧最多 20 张/实例、单张 ≤1 MB，检查 PNG 头与尺寸，保存时要求当前草稿修订匹配。PDF 包含关键帧索引，HTML 可显示本地图片；报告 JSON 包含完整原始状态。PDF 使用标准 CJK 字体映射，阅读器需支持中文字体替代。CSV 防公式注入，方向量的负值以文本导出，分析时需按数值导入。

可选网关 POST {model,input} → {text}，20 s 超时；仅发送实验名称、检查项与范围，密钥只读服务端环境。反馈不改变基础检查或教师成绩；失败返回错误，仍可使用本地解释。
