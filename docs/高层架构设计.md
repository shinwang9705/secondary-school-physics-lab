# 高层架构设计（优化版）· v1.0

登录 → 目录/班级任务 → 模型与器材 → 操作与手动测量 → 修订保存 → 服务端复算 → 基础反馈 → 教师评分 → 报告与回放。

| 模块 | 实现 |
| --- | --- |
| 42 项目录、实例目标和版本 | core/catalog.mjs |
| 自由电路、几何光学、原六项力学 | public/experiments、core/circuit.mjs、core/mechanics.mjs |
| 新增 28 项测量/运动/热学/电磁/波动光学 | public/physics/laboratory.js、laboratory-render.js |
| 身份、班级、任务、修订与评分 | server.mjs、core/platform.mjs |
| 逐实验参数校验和判定 | core/judge.mjs、共享模型检查 |
| 中文 PDF、HTML、CSV、JSON | core/reports.mjs |
| 关键帧与可选教学解释 | core/platform.mjs、public/platform-ui.js |
| 一致性快照与离线恢复 | VACUUM INTO、tools/restore.mjs |

单 Node.js 应用 + SQLite 数据卷，无 npm 外部依赖。浏览器负责高频显示，服务端按已保存参数复算；不逐帧通过 HTTP 求解。公式/SVG 模型适合本版参数范围；3D 通用引擎不是质量验收条件。

客户端不可信。实例固定模型/规则/资产版本，保留旧版本号；程序没有跨未知版本的自动迁移。未知版本禁止保存提交但可导出历史，避免静默改用新规则。教学解释与规则/教师成绩解耦，外部失败不改变成绩。
