# 安全设计 · v1.0

密码为独立 salt+scrypt；随机 token 32 字节，数据库只存 SHA-256 摘要；Cookie HttpOnly、SameSite=Strict、8 小时有效。每来源地址每分钟最多 15 次登录尝试。停用、角色/班级改变、重置或本人改密撤销相应登录会话；必须保留一个启用管理员。

学生仅能读取本人实验；带班教师及管理员可读取所辖学生记录，不能替学生修改原始状态。任务统计只对所辖教师/管理员开放。所有 API 校验权限；角色与带班由服务器决定。复核意见/评分追加历史，审计同事务保存。

修改 API 同源检查；JSON 上限 2 MB，状态字段/分度/历史数量和实验编号验证；快照复算不信任客户端派生读数。关键帧 PNG 限制数量、大小、头部尺寸，绑定最新保存修订；图片不进入自动判定。导出 HTML 转义文字，CSV 防公式注入。AI 密钥不下发前端，只发送公开实验名称与分项检查，不发送账号、原始记录和截图。

审计记录用于追踪，数据库管理员仍可修改数据，不宣称不可篡改。快照、客户端事件和截图不构成可信监考证据。教师评分是人工复核字段，与客户端生成 PASS 分开。

默认只监听回环 HTTP；局域网/公网须使用 TLS 反向代理、COOKIE_SECURE=1 和受控访问。备份包含账号与原始数据，下载到独立受控磁盘；没有公开分享和外部对象存储。本版没有第三方邮件/短信密码找回，管理员可验证身份后重置密码。数据删除/保留年限由使用单位另行确定，不能直接删除数据库行作“合规清理”。
