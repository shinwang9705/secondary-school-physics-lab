# 需求基线（优化版）· v1.0

目标：个人开发、本地部署、浏览器内完成初中 21 项与高中 21 项共 42 项教学仿真实验。全部入口开放，具备可调条件、模型现象、多组记录、保存恢复和逐实验规则反馈；不是以目录数量替代模型实现。

平台包含管理员/教师/学生、班级与多教师带班、任务期限与说明、提交统计、历史修订回放、教师复核评分历史、关键帧、JSON/CSV/HTML/PDF 报告、账号维护及一致性备份/离线恢复。默认本地规则解释；可配置外部教学解释网关，经用户选择才发送实验名称、检查项和反馈范围。

原始数据提交后锁定。教师评分与自动教学检查分开保存，后续复核追加历史。服务端复算数值和器材条件，但自洽客户端伪造仍不能由复算识别；不把自动 PASS、快照或截图当作真实操作考核证据。

验收分为模型与边界、保存提交闭环、角色权限、页面交互、报告和恢复。自动化和浏览器验证记录见开发进度。Docker 运行、实际外部模型服务、目标学校负载和教研质量验收属于部署/运营验证，不作为当前代码已经验证的事实。
