# 用户故事与验收 · v1.0

| 用户行为 | 验收 |
| --- | --- |
| 初次建立管理员 | 空库才能 setup，无默认密码 |
| 管理账号 | 创建、修改姓名/角色/班级、停用、密码重置；保护最后启用管理员，敏感授权变化撤销会话 |
| 管理班级 | 改名、多教师带班，教师只看所带班学生 |
| 布置实验 | 42 项可选、截止时间与说明；学生按所属班级进入任务 |
| 进行实验 | 调条件、观察现象、填写/记录测量、图表选择与拟合 |
| 保存/恢复/撤销 | 修订冲突保护；恢复和动态撤销后暂停 |
| 提交 | 服务端复算，幂等、锁定原始记录，错误给分项反馈 |
| 看班级进度 | 每位学生草稿/提交/逾期与教师评分 |
| 复核评分 | 0—100 分、通过/需补做；追加意见与评分历史，自动结果保持 |
| 回放/关键帧 | 看已保存快照，不改原记录；画面绑定保存修订 |
| 导出报告 | JSON/CSV/HTML/PDF；权限与原记录一致 |
| 获取解释 | 默认本地；明确选择后调用已配置网关，不传账号/记录/图像 |
| 备份恢复 | 管理员一致性快照下载，离线恢复前自动保留旧数据、撤销会话 |

以上为已实现代码范围。自动化/页面验证及未验证的运营环节见开发进度；逐实验教学质量与完整操作考核不以代码通过作为代替。
