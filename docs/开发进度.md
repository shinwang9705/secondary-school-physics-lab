# 开发进度 · 2026-10-10 · v1.0

## 交付范围

42 项全部具备可操作教学模型（初中 21、高中 21），保留既有 14 项，新增 28 项测量、热学、摩擦/压强、运动与碰撞、RC、材料/电源测量、波动光学、电磁/控制、油膜与理想气体。目录没有待开发入口。

新增实验共用参数规格、SVG 器材、整数步长、读数、手动测量、独立历史条件、图表勾选/拟合与结论；每项另有服务端规则。恢复与修改条件后暂停，动态运动可观察与定位时间。RC 切换时按 0.01 V 分度保留电压。

平台完成：多教师带班、账号维护/停用/改密/重置及会话撤销；班级任务说明/截止时间/绑定实例/提交统计/逾期；教师评分和改判历史；快照回放；本地关键帧；JSON/CSV/HTML/PDF 报告；一致性快照、周期备份配置及离线恢复；可选教学解释网关（默认关闭）；保存冲突保护、提交锁定与角色隔离；启动迁移及实例版本检查。设计文档同步更新。

## 当前边界

“42 项完成”指本轮教学仿真代码覆盖，不代表所有真实仪器细节或完整操作考试。既有电路/几何光学按用户认可的原型保留，其极性/调零时序、三线共面、玻璃板替代重合定位等完整动作仍有模型限制；新实验的刻度、运动、热力学与电磁也采用详细设计中的理想近似。文字结论与正式教学评分需要教师核查，客户端快照/截图不能证明真实操作。

未知模型/规则/资产版本禁止静默保存提交；没有跨未知版本转换。回放粒度为成功保存修订，不能恢复中间所有动作。PDF 使用中文标准 CID 字体与阅读器字体替代，HTML 带关键帧，PDF 仅列关键帧索引。

尚未执行 Docker 构建/容器启动、真实外部 AI 连接、目标学校课堂负载或逐实验教研验收。周期备份依赖应用运行与磁盘空间；应把快照下载至独立磁盘。生产 TLS/监控/数据保留由部署环境配置。
