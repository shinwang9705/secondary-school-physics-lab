# 首批仿真实验详细设计

## 通用器材与模型

电学：电源、电阻、开关、两端变阻器、固定电阻灯泡、电流表、电压表和导线。节点由导线与闭合开关合并；按电导和电源约束组建线性方程，带主元消元求解。仪表内阻分别为 0.01Ω 与 1MΩ，显示读数不一定等于理想无仪表值。范围与模型简化在实验页面说明。

光学：凸透镜采用 v=fu/(u-f)，u=f 为无有限像距，u<f 为虚像；成像清晰阈值采用 |s-v|≤1cm。反射角相对法线等于入射角；平面镜像距等于物距，正立等大虚像。第一阶段不模拟波动光学和实际镜面缺陷。

## 验证案例

理想电源3V、10Ω应为0.3A；两个10Ω串联为0.15A，并联每支路0.3A。仪表加入后按内阻复算；短路和矛盾电源应提示异常而非显示任意数值。

f=15cm时，u=45cm得到v=22.5cm，u=30cm得到v=30cm，u=10cm为虚像，u=15cm无有限像距。焦点条件保存不允许无效参数，无穷理论结果转为null，不影响原始f/u/s恢复。

同一初始状态及连接数据复算一致；伪造电流或电压记录不能通过；三次相同条件不能冒充控制变量实验。提交后保持原数据，缺少可复算历史快照的导入读数不能算有效记录。
