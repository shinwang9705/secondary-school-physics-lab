# 中学物理虚拟仿真实验室 · v1.0

42 项教学实验全部开放：初中 21 项、高中 21 项。支持测量、力学、电学、光学、热学、电磁与微观估测；包含器材条件、实验现象、手动记录、多组分析、保存恢复和服务端基础检查。

## 启动

需要 Node.js 24 或更高，无需安装 npm 依赖。双击启动实验室.cmd，或本目录运行 npm start；访问 http://127.0.0.1:4173。首次自行创建管理员，无默认账号/密码。管理员创建教师、班级、学生；教师可布置班级实验与截止时间。

## 实验与平台

- 电路台自由添加/移动/旋转/连线元件；凸透镜移动物体和光屏。保留此前接受的电学/光学作品。
- 其他实验调节器材条件与数值、观察图像/仪表、手动填写测量；动态实验可运行/暂停/定位仿真时刻，改参数重计时。每行保留测量时参数。
- 数据图表可勾选同轮测量，选择横纵轴并拟合直线；电动势/内阻实验填写拟合结果。按目标完成控制变量或重复测量。
- 自动保存和修订撤销/重做；历史回放按保存快照查看，关闭后恢复最新状态。提交后原记录锁定，补做请新建实例。
- 本地关键帧绑定修订；导出 JSON、CSV、HTML（带关键帧）及中文 PDF（关键帧索引）。
- 教师查看班级提交、逾期与分数，追加复核和改判历史；基础自动检查和教师成绩分开。
- 管理员可维护账号、停用、重置密码、调整班级/多教师，查看审计与创建备份。本人可改密，之后重新登录。

## 可选解释服务

默认本地解释，全部实验无需 AI。复制 .env.example 为 .env，配置 AI_GATEWAY_URL/AI_GATEWAY_KEY/AI_MODEL。网关协议 POST {model,input}，返回 {text}。页面勾选后才外呼，只发送实验名称、检查项与范围，不发送账号、原始记录或图片，不改变成绩。适配器已使用本地模拟网关测试，实际供应商接口需独立配置验证。

## 备份与恢复

管理员创建 SQLite 一致性快照并下载；可设 BACKUP_INTERVAL_HOURS 自动保存。把备份移到独立磁盘。恢复先停止应用，执行：

    node tools/restore.mjs "备份完整路径.sqlite" "data" --server-stopped

旧数据先保存为 before-restore 文件，恢复后登录会话撤销。详细步骤见 docs/部署设计.md。

## 验证和边界

运行 npm test。模型、权限、保存提交、报告、关键帧、任务/评分、备份恢复及可选 AI 适配器使用隔离数据验证；具体结果见 docs/开发进度.md。

这是一套教学仿真平台，自动 PASS 只表示基础规则通过，不能证明真实操作或替代教研验收。模型采用各自说明的理想近似；既有电路台未实现全部仪表调零时序考核，光学未模拟真实插针等全部器材步骤。文字结论需教师复核。正式考试、目标学校负载与 Docker 运行仍需专门验收。PDF 阅读器需支持中文字体替代；HTML 报告也可打印为 PDF。

默认本机回环地址。需要班级网络访问时按部署设计配置 TLS 与访问控制。设计文档位于 docs/设计索引.md；用户原始文件未覆盖。
